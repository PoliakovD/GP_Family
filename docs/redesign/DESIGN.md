# FamilyHub — дизайн-спецификация редизайна

Источник правды для редизайна. Направление: «Гибрид A+B» — спокойный светлый интерфейс
с мягкими карточками (A) и плотными рабочими элементами там, где много данных (B).
Макеты: `docs/redesign/screens/` (главная, семья и чат, анализ, дневник — десктоп 1440 и мобайл 390).

Если макет и этот документ расходятся — прав документ. Если чего-то нет ни там, ни там —
выбирай ближайший существующий паттерн отсюда, а не придумывай новый.

---

## 1. Принципы

1. **Спокойствие и доверие.** Пользователь часто приходит с тревогой. Мало цвета, много воздуха,
   цвет — только для смысла (статус, акцент действия).
2. **Один смысл — один цвет.** Опасность/вне нормы — только `danger`. Предупреждение — только
   `warning`. Норма — только `success`. Акцент (`accent`) — только действия и навигация,
   никогда не статус.
3. **Сначала то, что требует действия.** На обзорных экранах блок «Требует внимания» — список задач,
   у каждой строки своя кнопка действия.
4. **Плотность по контексту.** Обзоры — карточки с воздухом. Данные (анализы, показатели, админка) —
   плотная таблица/список внутри карточки.
5. **Доступность — ограничение, а не пожелание.** Базовый кегль 16–17px, тап-зона ≥ 44px,
   контраст текста ≥ 4,5:1, у иконочных кнопок `aria-label`, фокус всегда видим.
6. **Mobile first для PWA.** Каждый экран обязан работать на 390px. <1024px — нижний таб-бар,
   ≥1024px — сайдбар.

- Аватары участников: свой — `accent`/`on-accent`, остальные — циклически из набора мягких фонов

### 2.3. Типографика

Шрифт: **Onest** (400/500/600/700), self-hosted woff2 с кириллицей; fallback

`--font-mono`. Кегли `--text-*` в rem от `html { font-size: 100% }` — следуют системному размеру
шрифта. Числа в метриках и таблицах — `font-variant-numeric: tabular-nums`.

### 2.6. Тени и рамки

Карточки на `bg` — **без тени и без рамки** (контраст surface/bg достаточен).
Рамка `1px var(--color-border)` (≥ 2:1, решение владельца продукта) — только у контролов (вторичные кнопки, инпуты, вкладки) и
у вложенной карточки внутри surface (карточка анализа в чате).
Тени: `--shadow-segment: 0 1px 2px rgba(23,25,28,.08)` (активный сегмент),
`--shadow-fab: 0 8px 24px rgba(36,86,200,.35)` (FAB), `--shadow-overlay` для модалок/меню.
Цветные полосы слева у карточек (старый стиль дневника) **удаляются** — вид записи
показывает иконка в цветной плитке.

### 2.7. Иконки

Линейные, stroke 1.8 (навигация моб. 1.9), скруглённые концы, 20px (в плитках 20–22,
в строках действий 18). Одна библиотека на всё приложение — Lucide (`lucide`), рисует `app-icon`;
в данных иконка — `IconNode`, не строка класса. Эмодзи вместо иконок не используются.

## 3. Компоненты

У каждого: состояния default / hover / pressed / focus-visible / disabled, а где уместно —
loading и empty. Focus-visible: `outline: 2px solid var(--color-accent); outline-offset: 2px`.

### Кнопки
| Вариант | Вид |
|---|---|
| `primary` | bg accent, текст on-accent, 46px (в тулбарах 44), radius-md, 15px/600, опц. иконка 18px слева |
| `inverse` | bg inverse, текст on-accent — главное действие в строке задачи («Разобрать») |
| `secondary` | bg surface, рамка border, текст text, 15px/500–600 |
| `ghost` | без фона и рамки, текст text-secondary |
| `dashed` | рамка `1px dashed border-dashed`, текст accent-hover — «Пригласить», «Создать ссылку» |
| `icon` | 44–46px квадрат, radius-md; на мобайле в шапке — круг; обязателен `aria-label` |
| `fab` | моб.: 60px, radius 20, accent, shadow-fab, над таб-баром справа (bottom 100px) |
| `danger` | только для необратимых действий в подтверждении; текст danger, в меню «Ещё» |

На странице — одна primary-кнопка. Редкие действия (редактировать, удалить) уходят в меню «⋯».

### Поля
- `input` / `search`: 46px, surface, рамка border, radius-md, 16px; плейсхолдер text-muted;
  в поиске иконка 18px слева. На мобайле поиск — иконочная кнопка, раскрывающая поле.
- Ошибка: рамка и текст подсказки danger, иконка, текст под полем 14px.
- Каждое поле с `<label>` (видимым или визуально скрытым).

### Бейдж (`badge`)
Пилюля, 12–14px/600, паддинг 4×10 (моб. 3×8). Варианты: `danger`, `warning`, `success`,
`accent`, `neutral` — фон `*-soft`, текст основной цвет статуса.
Счётчик (`count-badge`): мин. 20–22px круг, 12px/600, danger или accent, текст on-accent.
Чип мета-данных (`meta-chip`): пилюля surface на bg, 32px, 15px, опц. мини-аватар 24 слева;
`meta-chip-accent` — «Видна семье» (accent-soft). На мобайле ряд чипов — строка текстом через «·».

### Карточки
- `card` — surface, radius-xl/2xl, паддинг 20–24, без рамки и тени.
- `metric-card` — подпись (15px muted) → число (metric, tabular) → бейдж или подпись. Целиком ссылка.

  На мобайле время уходит в подпись.

### Навигация и переключатели
- Сайдбар ≥1024px: 248px, surface, рамка справа. Сверху лого, затем **переключатель семьи**
  (52px, surface-muted, рамка), затем пункты 46px radius-md (активный — accent-soft + accent-hover
  600). Подпункты раздела — 38px, отступ 46px, активный — accent-hover 600. Внизу — пользователь.
  Групповые CAPS-заголовки внутри меню удаляются.
- Таб-бар <1024px: 4 пункта (Главная, Здоровье, Семья, Профиль), 84px с safe-area,
  иконка в «пилюле» 56×30 (активная — accent-soft), подпись 12px. Точка-индикатор новых сообщений
  у «Семьи».
- `tabs-pill` (разделы семьи, фильтры дневника): пилюли 40–42px, активная — inverse, остальные
  surface + рамка; со счётчиком внутри. На мобайле — горизонтальный скролл.
- `segmented` (сортировка, «Я / Близкие»): контейнер surface-sunken или surface+рамка, паддинг 3–4,
  сегменты 36px radius-sm, активный — surface + shadow-segment (или inverse для «чей»).
  В коде: `.seg` — surface + рамка (на bg), `.seg-sunken` — утопленный (внутри карточки),
  `.seg-inverse` — активный inverse.
- «Назад» — **один** компонент `BackLink`: шеврон 18 + текст 15/600 accent, высота 44.
  На мобайле — иконочная кнопка в шапке.

### Чат семьи
- Первая вкладка раздела «Семья», со счётчиком непрочитанных.
- Десктоп: чат (flex 2) + правая колонка (участники, доступ, заявки).
  Мобайл: полноэкранный, шапка (назад, аватар семьи, «в сети», ⋯), вкладки, без таб-бара.
- Пузырь входящий — bubble-in (на мобайле на bg — surface), аватар 32–36 слева, имя над первым
  в серии. Свой — accent, справа, без аватара. Макс. ширина 72% (моб. 84%). Время 12px muted под
  пузырём, у своего — «прочитано».
- Системные сообщения — по центру, пилюля surface-sunken 13px muted. Разделитель дня — 13/600 muted.
- **Карточка записи в чате** (анализ, приём, аптечка): вложенная карточка с рамкой, icon-tile,
  название + дата + статус-бейдж текстом, шеврон, ведёт на запись.
- Композер: «+» (прикрепить запись/файл) → поле surface-sunken → кнопка отправки accent.
  Всё 44–46px.

### Анализ
- Три счётчика-фильтра сверху (вне нормы / в норме / без нормы): `button` с `aria-pressed`,
  активный — рамка 2px статуса + soft-фон.
- Таблица в карточке: шапка surface-muted 13/600 muted; колонки Показатель / Результат /
  Где относительно нормы / Статус; строки разделены divider; в узком контейнере —
  горизонтальный скролл внутри карточки.
- **Шкала нормы**: трек 8px range-track, зелёный отрезок нормы занимает центральные 50% ширины,
  маркер 6×18 цвета статуса с белой обводкой, подписи границ 12px под отрезком. Положение маркера
  ограничено 3–97%.
- Мобайл: строки-карточки (название + значение в одну строку, шкала, бейдж статуса).
- Розовая/зелёная заливка целых строк **удаляется** — статус несут маркер и бейдж.

## 4. Каркас страниц

- Десктоп: сайдбар + контент; контент `max-width` 1000–1200px, паддинг 28–40px. Сайдбар и контент —
  один блок по центру (до 248 + 1200 + 2×40 = 1528px): на широком экране поля слева от навигации и справа
  от контента, а не пустая полоса между ними (у сайдбара тогда рамка с обеих сторон).
- Десктоп: поиск и колокольчик уведомлений — на всех страницах (над шапкой страницы). Глобальной
  кнопки «Добавить» нет (в т. ч. на главной): добавление — действием конкретного раздела.
- Шапка страницы: H1 + подзаголовок; справа действия (secondary…, одна primary, «⋯»).
- Формы добавления, справка и просмотр записи на десктопе — страница в колонке контента
  (`app-content-page`, `app-side-panel [page]`): ссылка «‹ Раздел» → (необязательная надпись) → H1 → карточка
  `surface` с формой (до 760px, широким формам — 960px). Список под ней скрыт; закрывают ссылка назад, «Назад»
  браузера и Esc, после закрытия — возврат к прежней прокрутке. Надпись над H1 не повторяет ссылку назад.
  Боковая панель справа остаётся только в админке. Телефон — как раньше: нижний лист / полноэкранный лист.
- Главная, десктоп: приветствие → метрики (полоса из 3 карточек) → «Требует внимания» (2/3) | семья
  с входом в чат + дни рождения (1/3). «Требует внимания» — самый крупный блок экрана, поэтому
  фокус на нём и без первой позиции.
- «Требует внимания» на Главной — и про близких: свежий (≤ 60 дней) анализ вне нормы и ближайшая прививка
  каждого, к чьим данным есть доступ (до 3 строк на тему). Такие строки подписаны «Имя · …» (подопечный — его
  имя в приложении), мои — «Вы · …»; если близких в блоке нет, подписей нет вовсе.
- Главная, мобайл: приветствие → «Требует внимания» → метрики → дни рождения. Места мало, поэтому
  то, что требует действия (§1 п.3), идёт первым.
- Обзор «Здоровье»: переключатель «чьи данные» в шапке, блоки «Каждый день», «Медкарта»,
  «Инструменты» (nav-rows).
- Мобайл: шапка 44px-контролы, контент паддинг 16, нижний отступ под таб-бар ≥ 100px.
- Экраны без оболочки (вход, регистрация, привязка Telegram, приглашение, согласие, анкета профиля):
  одна карточка `app-auth-card` по центру фона. Главное действие — primary во всю ширину, второстепенные —
  secondary / ghost под ним. На шаге входа рядом вводный текст: слева на десктопе, под формой на телефоне.
- 404 — `empty-state` с одним действием «На Главную» внутри оболочки приложения.
- Лендинг (`/`, только гостю; вошедший и Telegram Mini App — сразу на Главную): шапка (знак, «Войти»,
  primary «Создать аккаунт» — на телефоне только «Войти») → герой: H1 `--text-hero` + лид + две кнопки, справа
  декоративное превью «Требует внимания» (строки как на Главной: подпись «Имя · …», кнопка действия) и
  карточка «Дни рождения» (`app-birthday-row`; `aria-hidden`, `inert`) → три демо главных фич
  (`app-landing-demo` + макеты `app-landing-mock`: ИИ-расшифровка анализа, страница «Здоровье», отчёт для
  врача) → «Так отчёт видит врач» (мини-страница PDF `app-landing-report-preview`, структура как у
  DoctorReportHtmlRenderer) → «А ещё» (карточки остальных возможностей) → «Начать — три шага» → карточка защиты данных (только то, что сказано в политике конфиденциальности) →
  финальный призыв → подвал со ссылкой на политику. Цвет иконок — по виду раздела (`kind-*`) или neutral.
