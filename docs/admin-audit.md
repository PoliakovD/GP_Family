## Решения владельца (2026-10-04)

- Следующими делаем все четыре блока бэклога: правка данных, журналы и история, статус фоновых
  задач, техдолг.
- **Смена биоматериала у статьи показателя:** разрешить; если для нового биоматериала уже есть статья
  с тем же названием — смена отклоняется с предложением объединить статьи.
- **Справочник:** переключение на другую статью с несохранёнными правками спрашивает подтверждение
  (тот же диалог, что при уходе со страницы).
- **Задачи:** добавить колонку «Причина отказа» и фильтр по ней в самом списке (тот же `?reason=`, что
  приходит из «Требует внимания»).

## Бэклог — данные есть, а в админке их не видно или не поправить

- [ ] **Заметка «вентиля» веб-поиска** показывается, но не редактируется — UI всегда отправляет
  прежнюю (`admin-web-search`, `web-search-valve.store.ts`).
- [ ] **Биоматериалы:** не видно синонимов (`GlobalSpecimenKb.Aliases` — сюда же уходит старое имя
  после объединения), источника и `NormalizedName`; `SpecimenSearchGroupItem.cacheRows`
  загружается, но не рисуется.
- [ ] **Показатель:** нельзя сменить биоматериал (в запросе правки нет такого поля; решено: разрешить,
  при конфликте — предложить объединение); не показаны
  `normalizedName`, `payloadVersion`, `createdAt`, `verifiedAt`.
- [ ] **Медикаменты:** нет объединения дублей и «переобогатить» (нет и эндпоинтов).
- [ ] **Журнал изменений** (`KbChangeLog`) пишется и для строк кэша, но показывается только в карточке
  статьи справочника — нет ни истории строки кэша, ни общего журнала.
- [ ] **Журнал вызовов:** API умеет фильтры `provider/from/to` и `stats.byDay`, UI их не использует;
  `jobId` — текст, а не ссылка на задачу.
- [ ] **Промпты:** в редактор грузится только активная версия — старые нельзя посмотреть/сравнить до
  отката; запасной текст из кода не показан.
- [ ] **Карточка задачи:** не используются `startedAt`, `origin`, `force`, `externalSearchAt`,
  `isTransientFailure`; `kbId` — сырой GUID, а не ссылка; в таблице задач нет колонки причины отказа
  (решено: колонка + фильтр).
- [ ] **Фоновые пакетные задачи** (пересчёт флагов, разметка единиц кэша, массовое переобогащение)
  после «поставлено в очередь» не показывают прогресс/итог.
- [ ] **Прогрев/пересборки:** виден только последний запуск; не видно входного списка прогрева
  (`SearchWarmupRun.NamesJson`) и попыток пересборки.
- [ ] «Одобрение» грузит до 500 строк без пагинации (`admin-review`, take=500).
- [ ] Безопасность → Статистика: не выводится `oldestDataProtectionKeyCreatedAt`.
