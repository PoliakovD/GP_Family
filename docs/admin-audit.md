## Решения владельца (2026-10-04)

- Следующими делаем все четыре блока бэклога: правка данных, журналы и история, статус фоновых
  задач, техдолг.
- **Смена биоматериала у статьи показателя:** разрешить; если для нового биоматериала уже есть статья
  с тем же названием — смена отклоняется с предложением объединить статьи.
- **Справочник:** переключение на другую статью с несохранёнными правками спрашивает подтверждение
  (тот же диалог, что при уходе со страницы).
- **Задачи:** добавить колонку «Причина отказа» и фильтр по ней в самом списке (тот же `?reason=`, что
  приходит из «Требует внимания»).
