# Ревью по модулям — 2026-08-02

Черновой аудит кодовой базы FamilyHub, проведён вручную по каждому модулю. Цель — выписать
несостыковки, потенциальные бреши безопасности и любые подозрительные места **для дальнейшей
обработки**, не для немедленного фикса. Часть находок — предположения/гипотезы, требующие
проверки, а не подтверждённые баги; это явно помечено в тексте каждого файла.

Формат каждого файла: 🔴 высокий приоритет (вероятная брешь/явный баг) → 🟡 средний (несостыковка,
стоит проверить и решить) → 🟢 низкий/на заметку (подозрительно, но не факт, что проблема) →
✅ проверено, проблем не найдено (чтобы не переаудировать одно и то же дважды).

  способ аутентификации во ВСЕХ интеграционных тестах (`ClientAs`/`CreateClientAs`). Убрать можно
  только вместе с переписыванием всего интеграционного набора на настоящий PWA-вход/регистрацию
  или подписанный Telegram initData — отдельная, крупная задача рефакторинга тестов, не быстрый
  фикс.
