Политика конфиденциальности FamilyHub

Настоящая политика описывает, как сервис FamilyHub (далее — «Сервис») обрабатывает персональные данные пользователей в соответствии с Федеральным законом № 152-ФЗ.

Оператор: Самозанятый Поляков Даниил Александрович, ИНН 910606697197.

1. Какие данные мы обрабатываем

  • Идентификационные данные: Telegram ID, имя пользователя, адрес электронной почты (при использовании входа через браузер).
  • Медицинские данные (специальная категория): записи об анализах, сканы медицинских документов, сведения о лекарственных препаратах, даты рождения.

2. Правовые основания обработки

Правовыми основаниями обработки являются: согласие субъекта на обработку (включая специальную категорию), предоставляемое при регистрации; исполнение договора (пользовательского соглашения) в части функционирования учётной записи и напоминаний.

3. Как данные защищены

  • Данные хранятся на серверах на территории Российской Федерации.
  • Медицинские таблицы псевдонимизированы: они связаны только с внутренним идентификатором (UUID), без ФИО, телефонов и адресов в открытом виде. Псевдонимизированные данные не позволяют определить субъекта без использования дополнительной информации, которая хранится отдельно и защищена.
  • Чувствительные поля и файлы шифруются (AES-256-GCM); ключи хранятся вне базы данных.
  • Передача данных — только по TLS.
  • Доступ к медицинским записям фиксируется в журнале аудита (кто, к чьим данным, когда) — без содержимого самих записей.

4. Кому доступны данные

Медицинские записи по умолчанию видны только их владельцу. Доступ членам семьи предоставляется исключительно владельцем записи и может быть отозван в любой момент. Обработка данных ИИ-инструментами выполняется только локальными моделями внутри контура Сервиса.

Оператор может привлекать для технического сопровождения Сервиса третьих лиц, обеспечивающих функционирование серверной инфраструктуры, при условии заключения с ними договоров, гарантирующих конфиденциальность и безопасность персональных данных. Перечень таких лиц предоставляется по запросу. Данные не используются для рекламы.

Сервис получает идентификатор Telegram ID и имя пользователя через API Telegram; дальнейшая обработка этих данных осуществляется исключительно на серверах в РФ. Сервис использует инфраструктуру Telegram для авторизации и интерфейса (Telegram Mini App). Пользователь самостоятельно использует клиент Telegram, передавая данные в рамках пользовательского соглашения мессенджера.

5. Права субъекта персональных данных

  • Право на доступ: выгрузка копии всех своих данных — раздел «Настройки».
  • Право на забвение: удаление аккаунта безвозвратно удаляет персональные данные, включая медицинские записи и файлы; удалённые данные покидают резервные копии в срок ротации бэкапов.
  • Отзыв согласия: равнозначен удалению аккаунта.
  • Право на уточнение, блокирование или уничтожение неточных либо незаконно обрабатываемых данных.
  • Право на обжалование действий или бездействия Оператора в Роскомнадзор или в суд.

Запросы направляются через форму в разделе «Настройки» и/или на контактный e-mail Оператора.

Персональные данные хранятся до достижения целей обработки или отзыва согласия, после чего подлежат уничтожению в течение 30 календарных дней. Логи аудита доступа хранятся 1 год с момента события, после чего удаляются.

6. Изменения политики

При существенном изменении политики или текста согласия Сервис запросит подтверждение новой версии при следующем входе. История версий хранится у Оператора.
