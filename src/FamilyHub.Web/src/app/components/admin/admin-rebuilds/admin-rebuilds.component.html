Перепрогон норм показателей

Показатели, распознанные ДО фикса расчёта нормы (односторонний референс "<47"/">47" в тексте бланка, качественный результат вида "не обнаружено" без сравнения по смыслу) застряли на "нет данных" навсегда — обычная дозапись справочника их не подхватывает. Перепрогон пересчитывает такие показатели заново по уже сохранённым данным, без повторного распознавания документа. Часть показателей останется без нормы законно — если в бланке её нет.

Единицы измерения в кэше поиска

Кэш платного поиска, накопленный до того, как в запрос стали добавляться единицы, не знает, для каких единиц в сохранённой выдаче есть нормы. Один вызов локальной модели на строку кэша определяет это; дальше показатель с новой единицей берёт нормы из кэша без платного запроса. Платных вызовов нет; фоновая задача, батчами по 20 — запускайте один раз.

Переобогащение показателей со старой схемой

Когда схема карточки показателя обновляется, уже сохранённые строки остаются со старой. Переобогащение обновляет их батчами по 25 штук. Первый батч запускается сам после миграции схемы — повторяйте отсюда, пока строк со старой схемой не останется. Если таких строк нет, задача завершается сразу.
