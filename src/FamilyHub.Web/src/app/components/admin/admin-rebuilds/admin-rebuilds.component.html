Пересборка справочника показателей

Пересчитывает ключи уже распознанных показателей новым нормализатором (снимает нумерацию пункта бланка, КАПС), очищает справочник анализов и наполняет его заново поверх уже оплаченного кэша поиска — новых внешних запросов не потребуется. Разовое действие после деплоя исправлений очистки имён/резолвинга источника, не автоматическое.

Перепрогон норм показателей

Показатели, распознанные ДО фикса расчёта нормы (односторонний референс "<47"/">47" в тексте бланка, качественный результат вида "не обнаружено" без сравнения по смыслу) застряли на "нет данных" навсегда — обычная дозапись справочника их не подхватывает. Перепрогон пересчитывает такие показатели заново по уже сохранённым данным, без повторного распознавания документа.

Переобогащение показателей со старой схемой

Когда схема карточки показателя обновляется, уже сохранённые строки остаются со старой. Переобогащение обновляет их батчами по 25 штук. Первый батч запускается сам после миграции схемы — повторяйте отсюда, пока строк со старой схемой не останется. Если таких строк нет, задача завершается сразу.
