# E2E-сценарии (Playwright)

Сквозные проверки против **реального** стека: Postgres и MinIO в docker, настоящий API
(`dotnet run`, Development) и dev-сборка Angular, которую API сам раздаёт из `wwwroot`.
Нужны: Docker, .NET SDK, Node 20+.

```bash
cd e2e
npm install
npm run install-browsers      # один раз: скачивает Chromium
npm test                      # поднимет стек, прогонит сценарии, всё остановит
```

Что делает `support/global-setup.ts`: собирает фронт (`ng build --configuration development`),
стартует контейнеры `fh-e2e-postgres` / `fh-e2e-minio` (порты 54329 / 54339), запускает API на
`http://127.0.0.1:5290`. Логи API — `e2e/.artifacts/api.log`.

## Быстрый цикл отладки

```bash
E2E_REUSE=1 E2E_SKIP_BUILD=1 npx playwright test 03        # стек остаётся жить между запусками
E2E_STOP=1 E2E_REUSE=1 npx playwright test                 # тот же прогон, но с остановкой стека в конце
```

`E2E_SKIP_BUILD=1` не пересобирает фронт (после правок фронта — уберите). Если стек упал —
`docker rm -f fh-e2e-postgres fh-e2e-minio`.

## Как устроено

- **Вход** — dev-заголовок: в dev-сборке фронт кладёт `?devTgId=…` в localStorage и шлёт
  `X-Dev-TelegramId`; сервер заводит пользователя сам. Данные сценарии готовят через API
  (`support/api.ts`), интерфейс проверяют глазами пользователя. PWA-вход по email+паролю — свои
  сценарии (`17`, `18`): код из письма отдаёт `GET /dev/last-otp`.
- **ИИ «недоступен»**: `LmStudio__BaseUrl` указывает на закрытый порт, поэтому сценарии
  `05-ai-unavailable` проверяют плашку и состояние «ждём ИИ» без реальной модели.
- Rate-limit `/api/auth/*` в e2e-стеке поднят (все запросы с одного IP), включая `AuthSessionPermitLimit`
  для `/me` — иначе длинный прогон упирается в 429.
- **Gotenberg** в e2e-стеке не поднят: отчёт для врача проверяется до PDF (счётчик, «нет данных»,
  понятная ошибка «сервис документов временно недоступен»).
- Один воркер; у каждого сценария свой пользователь, так что порядок не важен.

## Сценарии

| Файл | Что проверяет |

| `05-ai-unavailable` | плашка «ИИ недоступен», «ждём ИИ», задача уходит вместе с записью |

| `07-mobile-nav` | нижняя панель на телефоне |

| `21-dependent-add` | подопечный и питомец из формы: проверка полей, день рождения во вкладке и на экране |

## CI

Workflow `.github/workflows/e2e.yml` запускает набор на push в `master`, вручную (`workflow_dispatch`) и на PR,
которые меняют `src/FamilyHub.Web/**` или `e2e/**`. При падении выгружает артефакт `e2e-report` (HTML-отчёт Playwright,
трейсы, `api.log`). Устройство стека, грабли и политику зависимостей см. в
[`.claude/research/frontend-toolchain-and-e2e.md`](../.claude/research/frontend-toolchain-and-e2e.md).
