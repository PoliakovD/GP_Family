# FamilyHub — правила для Claude Code

## UI / дизайн
- Источник правды по дизайну: docs/redesign/DESIGN.md и макеты в docs/redesign/screens/.
- Никаких литералов цвета, font-size, отступов, радиусов и теней в компонентах — только токены
  из styles.scss. Нет нужного токена — сначала добавь его в styles.scss и в DESIGN.md.
- Новые UI-элементы — только из общих компонентов/классов. Нет нужного — сначала добавь
  в библиотеку, потом используй.
- Цвета статусов только по смыслу: danger — вне нормы/просрочено/ошибка, warning — скоро/выше
  рекомендуемого, success — норма. Accent — только действия и навигация.
- Тап-зона ≥ 44px, текст ≥ 12px, контраст ≥ 4,5:1, aria-label у иконочных кнопок.
- Каждый изменённый экран проверяй скриншотами на 1440 и 390 и сравнивай с макетом.
- Одна фаза/модуль — один PR. Не смешивай редизайн с изменением логики.
- План редизайна по фазам: docs/redesign/PLAN.md. Скриншоты до/после и сравнение с макетом —
  стенд e2e/visual/ (см. e2e/visual/README.md).
